# 에이메스 독립 프로그램

Windows 전용 WebView2 창이 현재 프로젝트의 `http://127.0.0.1:8765/`를 표시합니다. 주소창·브라우저 탭·사이드바가 없고 자체 창/작업표시줄 아이콘으로 실행됩니다. Windows 바탕화면/셸 자체를 교체하지 않습니다.

## 빌드

`desktop-app/build.ps1`을 PowerShell에서 실행합니다. 기본값은 기존 Python 3.10이며, 다른 서버 환경은 `-PythonPath`로 지정합니다. `-DesktopShortcut`은 기존 파일을 덮어쓰지 않고 바탕화면에 `에이메스.lnk`를 만듭니다.

- Microsoft 공식 NuGet의 `Microsoft.Web.WebView2` **1.0.4258.31**만 다운로드하고 로더의 Microsoft Authenticode 서명을 확인합니다.
- Windows의 기존 .NET Framework 컴파일러와 WebView2 Runtime을 사용합니다.
- 결과물은 `local_backups/desktop-app/bin/Aemeath.exe`, 프로필은 `local_backups/desktop-app/user-data`입니다. 이 폴더는 비공개이며 기존 Git 제외 규칙에 포함됩니다.
- 프로젝트와 분리해서 exe만 이동하지 마세요. 기존 소스와 Python 설치를 사용하는 로컬 실행기이며 독립 배포 설치 패키지가 아닙니다.

## 실행과 종료

실행하면 기존 오피스 서버를 확인하여 재사용하고, 없으면 기존 Python으로 서버를 숨김 실행합니다. 새 일반 브라우저 창은 열지 않습니다. 반복 실행은 기존 에이메스 창을 표시합니다. 창을 닫아도 서버나 진행 중 업무를 종료하지 않으며 기존 브라우저 창을 강제로 닫지 않습니다.

Codex 연결을 사용하는 현재 구조에서는 Codex 앱을 계속 켜두어야 합니다. 기존 업무용 Chrome/로그인 세션과 별도로 Office 표시용 WebView 프로필만 사용합니다. 다운로드는 저장 대화상자, Office 파일 미리보기는 별도 전용 창, 외부 HTTP(S) 링크는 기본 브라우저로 엽니다. 임의 native 메시지 API는 노출하지 않습니다.

타부서 요청은 기존 앱에서 브라우저별 localStorage에 저장됩니다. 최초 이전 시 `migrate_requests.py --client-id <기존 실제 탭ID>`로 해당 탭이 마지막 동기화한 요청 목록만 비공개 seed에 복사할 수 있습니다. 최근 30분 이내의 정확히 선택한 탭만 사용하며 새 창의 해당 저장 키가 없을 때에만 한 번 적용합니다. 기존 브라우저의 쿠키·계정·프로필을 복사하지 않습니다. 전환 후에는 전용 앱을 주 화면으로 쓰세요. 이전 브라우저와 새 앱의 이 목록·창 배치가 실시간 공유되는 구조는 아닙니다.

## 자체 수정

화면과 서버는 기존 편집 가능한 프로젝트 원본을 그대로 사용합니다. 기존 자체 수정·업무 기록·DB·설정 경로를 유지합니다. 화면 소스는 기존 앱의 갱신 경로가 반영하고, 백엔드 재시작 동안에도 데스크톱 창은 살아 있으며 연결이 복구되면 다시 표시합니다. C# 실행기 자체를 바꾸는 경우에만 창을 닫고 다시 빌드합니다.
