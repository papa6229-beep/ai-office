기본 운영 화면 안내

왼쪽은 업무와 채팅, 오른쪽은 자주 쓰는 프로그램·웹사이트·폴더 실행판입니다.

실제 AI OFFICE 열기
채팅에 평소 말하듯 요청하세요. ‘포샵이랑 일러스트 바로가기로 만들어줘’, ‘계산기 좀 띄워줘’, ‘바탕화면 살펴봐줘’처럼 말하면 AI가 실제 기능을 찾아 수행합니다.

사용 순서

  1. 프로그램을 찾아 등록하거나 열어보세요.‘포샵이랑 일러스트 바로가기로 만들어줘’ → 오른쪽에 버튼이 생깁니다. ‘계산기 좀 띄워줘’는 앱을 엽니다. 정확한 영어 이름이나 고정된 문장을 요구하지 않습니다. 여러 후보가 있으면 채팅에서 선택합니다.
  2. 버튼을 누르면 바로 열립니다.‘편집’에서 이름·대상·이모지·이미지 아이콘을 바꾸고 순서를 조정하거나 등록을 삭제할 수 있습니다. 삭제해도 원본 프로그램과 파일은 유지됩니다.
  3. 업무를 추가하고 목록을 눌러보세요.왼쪽 채팅 또는 ‘업무 추가’로 등록합니다. 목록을 누른 팝업에서 상태·메모·관련 자료·시간순 진행 기록을 봅니다.

현재 사용할 수 있는 기능

원클릭 실행판

Windows 시작 메뉴 앱과 Store 앱, 로컬 EXE/LNK, HTTP/HTTPS 웹사이트, 작업 폴더를 엽니다. 프로그램 검색과 Chrome·Edge 북마크 선택을 지원하며 등록·아이콘·순서는 다시 열어도 유지됩니다.

내 아이콘

이모지·짧은 글자 또는 PNG/JPEG/WebP/ICO 이미지를 사용합니다. 이미지 최대 512KB·1024px, 검증 후 PNG로 저장합니다.

업무 진행 팝업

업무 목록에서 선택해 진행 상태·메모·자료 연결과 시간순 이력을 확인합니다. 팝업에서 기록을 저장해도 창을 유지합니다.

기존 자료 도구

‘내 자료 열기’에서 바탕화면·앱·파일, 이미지 판단, 복구 보관함과 기존 조사 도구를 사용합니다.

채팅에서 할 수 있는 일

앱·바로가기·북마크, 업무 기록·메모·보고, 바탕화면 조사·분석·중복 조사·가상 작업함·복구 보관을 같은 채팅으로 요청합니다. 실제 파일 보관·복원은 대상이 표시된 승인 버튼으로 실행합니다. 가상 묶음은 원본을 이동하지 않습니다. 기존 폴더 자동정리 정책 실행은 별도 화면을 사용하며 메신저·임의 화면 조작·영구 삭제는 아직 연결하지 않았습니다.

확인한 내용

Windows 자동 테스트 335개 통과. 실제 앱 실행 환경은 334개 통과·선택 PDF 1개 제외. 실제 Gemma로 자유로운 한국어 앱 등록·계산기 실행·내일 마감 업무 기록을 확인했습니다. 별도 시험 바탕화면에서 조사·내용 분석·승인 카드의 새로고침 유지·시험 파일 복구 보관과 원위치·내용 복원을 확인했습니다. 실제 사용자 자료는 시험 대상으로 사용하지 않았습니다.
