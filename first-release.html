기본 운영 화면 안내

왼쪽은 업무와 채팅, 오른쪽은 자주 쓰는 프로그램·웹사이트·폴더 실행판입니다.

실제 AI OFFICE 열기
채팅에 ‘바로가기에 코덱스, 포토샵, 일러스트레이터 추가해줘’라고 입력하면 설치된 앱을 찾아 등록합니다. 오른쪽 버튼으로 바로 열고, 업무 목록을 누르면 진행 과정 팝업이 열립니다.

사용 순서

  1. 채팅으로 자주 쓰는 프로그램을 등록하세요.‘바로가기에 포토샵, 일러스트레이터 추가해줘’ → 등록 후 오른쪽에 버튼이 생깁니다. 여러 후보가 있으면 채팅에서 선택하고 이미 등록된 앱은 유지합니다. 웹사이트·폴더는 오른쪽 ‘+ 추가’를 이용하며 웹은 Chrome·Edge 북마크에서 고를 수 있습니다.
  2. 버튼을 누르면 바로 열립니다.‘편집’에서 이름·대상·이모지·이미지 아이콘을 바꾸고 순서를 조정하거나 등록을 삭제할 수 있습니다. 삭제해도 원본 프로그램과 파일은 유지됩니다.
  3. 업무를 추가하고 목록을 눌러보세요.왼쪽 채팅 또는 ‘업무 추가’로 등록합니다. 목록을 누른 팝업에서 상태·메모·관련 자료·시간순 진행 기록을 봅니다.

현재 사용할 수 있는 기능

원클릭 실행판

Windows 시작 메뉴 앱과 Store 앱, 로컬 EXE/LNK, HTTP/HTTPS 웹사이트, 작업 폴더를 엽니다. 프로그램 검색과 Chrome·Edge 북마크 선택을 지원하며 등록·아이콘·순서는 다시 열어도 유지됩니다.

내 아이콘

이모지·짧은 글자 또는 PNG/JPEG/WebP/ICO 이미지를 사용합니다. 이미지 최대 512KB·1024px, 검증 후 PNG로 저장합니다.

업무 진행 팝업

업무 목록에서 선택해 진행 상태·메모·자료 연결과 시간순 이력을 확인합니다. 팝업에서 기록을 저장해도 창을 유지합니다.

기존 자료 도구

‘내 자료 열기’에서 바탕화면·앱·파일, 이미지 판단, 복구 보관함과 기존 조사 도구를 사용합니다.

채팅과 실행 버튼

채팅은 업무 등록·메모·상태·기존 보고서 생성과 명시적인 프로그램 바로가기 추가 요청을 처리합니다. 오른쪽 실행 버튼은 등록한 프로그램·웹·폴더를 직접 엽니다. 메신저 파일 수신·전송과 앱·브라우저 자율 업무는 아직 연결하지 않았습니다.

확인한 내용

Windows 자동 테스트 289개 통과. 실제 앱 실행 환경은 288개 통과·선택 PDF 1개 제외. 별도 시험 DB에서 실제 설치 앱 3개 채팅 일괄 등록·중복 방지·선택 후보의 새로고침 후 유지·선택 등록·즉시 화면 반영을 확인했습니다. 편집 중인 입력 보존과 기존 사용자 바로가기·업무·설정 보존도 확인했습니다.
