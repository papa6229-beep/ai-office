업무를 등록하고 자료와 진행 기록을 연결해 하루 보고서를 만드는 개인 업무 비서 시험판입니다.

실제 AI OFFICE 열기
오늘의 업무가 새 기본 화면입니다. 채팅으로 업무를 남기거나 직접 등록하고, 선택한 업무에서 진행 메모와 관련 자료를 이어서 관리합니다.

지금 사용할 수 있는 기능

채팅 업무 지시

업무 등록, 선택한 업무의 메모와 상태 변경, 오늘 보고서 작성을 요청할 수 있습니다. 대화와 실제 처리 결과는 다시 열어도 유지됩니다.

업무와 자료 연결

업무명·설명·마감일과 파일·폴더 위치를 연결합니다. 한글 문서와 디자인 원본도 연결할 수 있으며 원본 위치와 내용은 유지됩니다.

진행 기록

예정·진행 중·완료 상태를 표시하고 메모를 남깁니다. 기존 업무 리스트에서 바꾼 기록도 같은 업무 이력에 남습니다.

일일 보고서

오늘의 등록·메모·자료 연결·상태 변경과 진행 중인 업무로 초안을 만듭니다. 저장한 초안을 다시 보거나 복사·텍스트 저장할 수 있습니다.

간단한 시험 순서

  1. 채팅으로 실제 할 일을 등록하세요.예: “내일까지 거래처 시안 검토를 업무로 등록해줘.” 응답 후 업무와 마감일이 생기는지 확인합니다. 직접 입력하려면 ‘업무 추가’를 사용하세요.
  2. 업무를 눌러 관련 자료와 진행 메모를 붙이세요.폴더 선택 또는 파일 경로 입력 → ‘자료 연결’. 진행한 일을 메모하고 ‘진행 중으로 표시’를 누르세요. 원본 파일은 이동하지 않습니다.
  3. ‘보고서 작성’을 누르세요.방금 남긴 기록과 진행 업무가 포함되는지 봅니다. 새로고침 후에도 업무·대화·자료·보고서가 남는지 확인하세요.

기존 자료 도구

  • ‘내 자료 열기’에서 바탕화면 앱·파일·폴더와 업무 작업함을 엽니다.
  • 문서·이미지 내용 분석과 후보 일괄 복구 보관·복원은 기존 화면에서 계속 사용할 수 있습니다.
  • PC 자료 조사·중복 비교·저장한 독립 폴더 자동 정리·업데이트도 유지됩니다.

현재 실행 범위

이 버전의 채팅 실행은 업무 등록·메모·상태·오늘 보고서까지입니다. 메신저 파일 자동 수신·전송, 앱·브라우저 업무 대행, 실제 스트림덱 기기 연동은 아직 연결하지 않았습니다. ‘완료 표시’는 사용자가 업무 상태를 바꾼 기록입니다.

확인한 내용

Windows 자동 테스트 239개 통과. 실제 앱 실행 환경은 238개 통과·선택 PDF 구성요소 미설치 1개 제외. 생성한 시험 DB와 파일로 업무 등록 → 자료 연결 → 메모 → 진행 상태 → 보고서 저장과 재조회를 화면에서 확인했습니다. 설정된 실제 Gemma에서도 시험 업무와 내일 마감일이 등록됐습니다. 기존 사용자 업무·실행 기록·설정은 보존했습니다.
