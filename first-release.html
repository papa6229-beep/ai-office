1차 기능 보고서

실제 바탕화면 내용을 AI가 읽고, 이미지 용도와 업무 관계를 판단하며, 확인할 후보만 보여주는 개발 버전입니다.

AI OFFICE 열기
사용자는 자동 내용 분석을 켜고, 이후에는 판단 결과와 한 번에 치울 후보를 봅니다. 파일마다 선택하거나 승인하는 방식은 줄였습니다.

지금 사용할 수 있는 기능

내 작업 데스크

실제 바탕화면의 앱·폴더·파일을 검색하고 엽니다. 즐겨찾기, 유형별 보기, 이미지 미리보기, 전체화면을 제공합니다.

자동 업무 작업함

실제 내용이 연결되는 자료를 AI가 앱 안에서 묶습니다. 이름에 따른 기존 묶음과 구별하며, 작업함 수정과 해제를 기억합니다. 원본 위치는 유지됩니다.

자동 폴더 정리

원본·보관 폴더와 제외 이름을 저장합니다. 자동 정리를 켜면 앱이 실행 중일 때 주기적으로 지원 파일을 유형별 폴더에 이동합니다.

처리 결과·되돌리기

이동·보류·충돌을 기록합니다. 중단된 작업은 이어갈 수 있고, 수정된 파일이나 새로 생긴 파일을 덮어쓰지 않고 되돌립니다.

PC 자료 조사·중복 비교

파일·폴더 현황을 카드로 확인합니다. 동일 내용 비교와 ZIP 내부 비교로 중복·관련 자료 후보를 찾습니다.

문서·이미지 자동 이해

파일 선택 없이 지원하는 실제 바탕화면 자료를 차례로 읽습니다. 작업 결과물·로고·짤·사진·초안 등의 용도와 업무 관계를 판단합니다. 내용이 연결되는 자료는 앱 작업함에 자동 반영합니다.

새 기본 흐름: AI가 먼저 살펴봅니다

작업 데스크의 AI로 바탕화면 살펴보기로 시작합니다. 결과가 차례로 나타나고, 열어보기·한 번에 치우기에서 파일을 바로 열거나 남겨둘 수 있습니다. 승인한 후보는 숨김 복구 보관함으로 옮기고 원위치 복원이 가능합니다. Windows 휴지통·영구 삭제는 실행하지 않습니다. 자동 작업함은 앱 안의 묶음이며 업무별 실제 폴더 이동은 아직 연결하지 않았습니다.

기존 시험 도구와 범위 설정

  1. 내 작업 데스크를 사용해 보세요.검색, 즐겨찾기, 파일 열기와 작업함이 일상 업무에 편한지 확인합니다.
  2. 시험 도구를 펼쳐 ‘샘플 이동 테스트’를 누르세요.앱이 만든 샘플 4개를 정리하고 1개를 보류합니다. ‘시험 파일 원위치 복원’으로 샘플 복원도 확인합니다. 실제 바탕화면 자료는 변경하지 않습니다.
  3. 별도의 작은 시험 폴더 두 개를 준비하세요.원본 폴더에는 프로젝트와 연결되지 않은 시험 파일 몇 개만 복사해 두고, 다른 기존 폴더를 보관 위치로 선택합니다. 중요한 원본으로 첫 시험을 시작하지 않아도 됩니다.
  4. ‘자동 폴더 정리’에서 범위를 저장하세요.원본·보관 위치, 제외 이름을 입력하고 범위 허용을 체크합니다. 저장·미리보기까지는 파일을 이동하지 않습니다.
  5. 미리보기 후 ‘자동 정리 시작’을 누르세요.60초마다 확인합니다. 최근 작성된 파일은 안정될 때까지 기다립니다. 바로 확인하려면 ‘지금 한 번 정리’를 사용합니다.
  6. 결과·보류 사유와 되돌리기를 확인하세요.되돌리기를 누르면 자동 정리가 일시 정지됩니다. 바뀐 파일은 보존하고 확인 대상으로 남깁니다.

자동 처리의 현재 범위

항목현재 동작
정리 대상저장한 독립 파일 수신함의 최상위 지원 파일. 하위 폴더는 이동하지 않습니다.
정리 기준파일 종류별 분류. Gemma가 내용으로 프로젝트를 판단해 자동 이동하는 기능은 이후 단계입니다.
이름 충돌·사용 중 파일덮어쓰지 않고 확인 대상으로 남깁니다.
AI·PSD와 보호 자료AI·PSD 등 프로젝트 원본이 있는 폴더는 연결 자료 보호를 위해 실제 정리를 보류합니다. 보호 파일도 이동하지 않습니다.
이동량한 작업 최대 100개, 파일당 20MB, 합계 200MB. 첫 묶음이 모두 충돌·사용 중이면 뒤의 자료도 대기할 수 있습니다. 같은 로컬 드라이브의 분리된 기존 폴더를 사용합니다.
내용 분석PC 조사 수동 분석은 선택한 자료를, 바탕화면 자동 분석은 지원하는 바탕화면 자료를 설정된 서버로 보냅니다. 폴더 정리 허용은 서버 전송 허용으로 사용하지 않습니다.
PDF·디자인 미리보기PDF 내용 추출에는 선택 구성요소 pypdf가 필요합니다. PSD에는 Pillow, AI 미리보기에는 Illustrator가 필요합니다.
자동 확인AI OFFICE가 실행 중일 때 작동합니다. PC를 끄거나 프로그램을 종료하면 멈춥니다.

보존과 복구

  • DB·설정·API 키·정리 기록은 GitHub에 올리지 않습니다.
  • 파일을 삭제하거나 기존 이름을 덮어쓰는 기능은 없습니다.
  • 정리 기록을 먼저 저장하고 이동합니다. 중단 후 기록과 실제 파일을 비교해 이어갑니다.
  • 되돌리기는 이후 바뀐 파일과 새로 생긴 원본 위치의 파일을 보존합니다.
  • 업데이트는 DB·설정을 백업하고 실패 시 변경한 코드만 조건부로 복구합니다. 실패 복구 후 자동 정리는 정지 상태로 돌아옵니다.

검증 결과

Windows 자동 검증 215개 통과. 생성한 파일로 내용 판단 → 업무 묶음 → 후보 일괄 보관 → 원위치 복원을 화면에서 확인했습니다. 좁은 화면의 가로 넘침과 브라우저 오류는 없었습니다. 실제 바탕화면에서도 설정된 Gemma로 문서・이미지 분석과 업무 묶음 반영을 확인했으며, 실제 파일의 치우기는 실행하지 않았습니다. 기존 DB·설정과 원본 파일은 보존했습니다.
