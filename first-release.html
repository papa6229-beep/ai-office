기본 운영 화면 안내

왼쪽은 업무와 채팅, 오른쪽은 자주 쓰는 프로그램·웹사이트·폴더 실행판입니다.

실제 AI OFFICE 열기
채팅에 평소 말하듯 요청하세요. ‘포샵이랑 일러스트 바로가기로 만들어줘’, ‘계산기 좀 띄워줘’, ‘바탕화면 살펴봐줘’처럼 말하면 AI가 실제 기능을 찾아 수행합니다.

사용 순서

  1. 프로그램을 찾아 등록하거나 열어보세요.‘포샵이랑 일러스트 바로가기로 만들어줘’ → 오른쪽에 버튼이 생깁니다. ‘계산기 좀 띄워줘’는 앱을 엽니다. 정확한 영어 이름이나 고정된 문장을 요구하지 않습니다. 여러 후보가 있으면 채팅에서 선택합니다.
  2. 카드를 누르면 바로 열립니다.모든 바로가기를 4열 카드 보드에서 위아래로 스크롤합니다. 우클릭으로 이름·프로그램·주소·아이콘과 160자 설명·표지 이미지/GIF를 바꾸세요. 표지는 가로 3:세로 2, 600×400px 또는 1200×800px를 권장합니다. 전체 보드에서 드래그로 순서를 바꿉니다. 바로가기 등록을 삭제해도 원본 프로그램과 파일은 유지됩니다.
  3. 업무를 추가하고 목록을 눌러보세요.왼쪽 채팅 또는 ‘업무 추가’로 등록합니다. 업무 행에 예정·진행중·검토중·완료 상태와 기록·자료 배지가 표시됩니다. 늘어난 업무는 목록 안에서 스크롤하고 상세 팝업에서 이력을 봅니다. 외부 일일보고서와의 자동 동기화는 아직 연결하지 않았습니다.
  4. WORKSPACE에서 과정과 결과를 보세요.실제 도구 실행 단계와 주문한 코드·문서·요약 결과물을 표시합니다. 일반 채팅 답변을 반복하지 않습니다. 파일 찾기와 연결 자료의 미리보기로 이미지·영상을 표시하고 확대할 수 있습니다. 코드는 결과가 도착한 뒤 표시하며 코드 초안을 보여주는 것과 실제 실행은 구별합니다.

현재 사용할 수 있는 기능

원클릭 실행판

Windows 시작 메뉴 앱과 Store 앱, 로컬 EXE/LNK, HTTP/HTTPS 웹사이트, 작업 폴더를 엽니다. 프로그램 검색과 Chrome·Edge 북마크 선택을 지원하며 등록·아이콘·순서는 다시 열어도 유지됩니다.

내 카드 꾸미기

작은 실행 아이콘은 최대 512KB·1024px, 별도 표지 이미지는 최대 4MB·2048px입니다. 표지에는 PNG/JPEG/WebP/GIF를 사용하며 움직이는 GIF를 유지합니다. 카드 설명과 표지도 채팅으로 바꿀 수 있습니다.

업무 진행 팝업

업무 목록에서 선택해 진행 상태·메모·자료 연결과 시간순 이력을 확인합니다. 팝업에서 기록을 저장해도 창을 유지합니다.

기존 자료 도구

‘내 자료 열기’에서 바탕화면·앱·파일, 이미지 판단, 복구 보관함과 기존 조사 도구를 사용합니다.

채팅에서 할 수 있는 일

앱·바로가기·북마크, 업무 기록·메모·보고, 파일·폴더 검색과 탐색기 위치 표시, 바탕화면 조사·분석·중복 조사·가상 작업함·복구 보관을 요청합니다. 보드 순서·카드 설명·표지·이미지/GIF 변경도 가능합니다. 이미 저장·허용한 폴더 정책은 실행·자동 처리 켜기/끄기·재개·되돌리기를 채팅과 화면에서 같은 기능으로 처리합니다. 새 정리 범위는 화면에서 설정합니다. 메신저 첨부 수신·저장·전달, 웹 양식 제출, 매뉴얼 자동 실행은 아직 미연결입니다.

확인 범위

이전 카드 보드·공통 기능은 254개 자동 테스트를 통과했습니다. 이번 WORKSPACE 변경은 해당 시험 결과에 포함되지 않으며 새 자동 테스트와 실제 Gemma 요청은 실행하지 않았습니다. 원본 업무 자료를 시험 변경하지 않았습니다.
