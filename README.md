# AI OFFICE v2.6 · 보기 쉬운 결과 + 업데이트 준비

- 기존 PC 조사/정리/프로젝트 비교 기능 유지
- **조사 결과에서 정리 후보 찾기**: 긴 텍스트 대신 4개 핵심 통계, 접이식 프로젝트 카드, 버전 그룹, 검토 후보 제공
- **텍스트·코드 미리보기**: 선택한 파일을 읽기 전용으로 최대 256KB까지 확인하며, 키·토큰·비밀번호 형식은 화면에서 가립니다.
- **개인 데이터 보호**: `office.db`, `settings.json`, 로그, 백업, Python 캐시는 Git 추적에서 제외합니다.
- **업데이트 실패 복구**: 업데이트가 바꾼 파일과 커밋만 조건부 복원하며, 전체 작업 트리를 강제 초기화하지 않습니다.
- 기존 시스템에서 가져온 `office.db`와 `settings.json`은 개인 데이터이므로 이 배포 패키지에 포함하지 않음. 기존 파일을 별도로 보관했다가 복사하세요.
- **업데이트 후 실행.bat**: Git 저장소가 연결된 이후부터 `git pull --ff-only` 후 실행. 현재 배포 저장소 미연결.
- 자동 파일 이동·삭제하지 않음. 기존 파일 정리 메뉴의 승인 기반 이동 기능은 유지됨.
- Windows 로컬 실행 검증은 별도 필요. Git 연결 절차는 UPDATE_GUIDE.md 참조.
