대표의 후속 피드백: 캐릭터가 서로 비슷하고3상태 차이가 약하다. 팀마다 다른 실루엣을 쓰고, 대기는 편안하게/작업은 분노/완료는 크게 행복하게, 배경도 넣는다.

| 팀 | 같은 팀 안에서 유지하는 캐릭터 |
|---|---|
| planning | 파란 조끼의 둥근 귀 곰 |
| design | 분홍 옷·큰 꼬리의 보라 고양이 |
| development | 안테나·네모 머리의 파란 로봇 |
| research | 둥근 얼굴·안경 테두리의 초록 부엉이 |

각 팀의 idle.gif/working.gif/completed.gif와 같은 이름의 PNG가 있다. 세상태 모두320×320 불투명 배경이며32px 논리 격자·팀별32색 팔레트로 인코딩했다. PNG는 움직임 줄이기용이다.

- idle: 파란 휴식 공간, 편안한 표정·느린 깜빡임/숨쉬기.
- working: 붉은 불꽃, 크게 찌푸린 눈·벌어진 입·책상/키보드/붓/책을 두드리는 동작. 분노는 요청한 코믹 표현이며 실제 실패를 뜻하지 않는다.
- completed: 노란 축하 공간·색종이·큰 웃음·두 팔/날개를 올린 점프.

GIF12개 모두4개의 서로 다른 프레임·무한반복. 대기2680ms, 작업640ms, 완료800ms. 내장 image_gen4시트로 생성하고 실제 행 경계를 확인해 잘랐다. 프롬프트/시트/비교 GIF·메타데이터는 local_backups/department-gifs-v2-20261026에 보존한다.

department-sprites.js는 작은 로더다. 기존 관리 정적 경로로4팀별 department-sprites-TEAM.js를 불러 실제 GIF/PNG를 제공한다. 배경을 넣은 데이터가 커져 팀별 묶음으로 나눴다. 서버 API·개인 캐릭터 registry·메인 에이메스 선택·3상태 판단/완료확인 규칙은 바꾸지 않았다. v1원본도 보존한다.
