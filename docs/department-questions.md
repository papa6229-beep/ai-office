# 기존 요원 대화의 확인 질문

버전: 2026-10-28.1 · 현재 PC의 등록 요원 9개 대화에 적용.

일반 확인·허가 질문은 해당 요원 작업창에 질문 원문과 답변란으로 표시한다. 객관식 선택지가 없어도 주관식 답변란을 만든다. 객관식 버튼은 답변란에 값을 채우며 사용자가 **답변 보내기**를 눌러야 전달한다. 별도 새 대화나 모델 호출을 만들지 않는다.

Office가 표시된 동안 2.5초 간격의 코드 조회로 등록 대화의 새 질문을 수신한다. 접힌/닫힌 작업창의 질문도 Office 화면 안의 알림에서 해당 기존 대화로 연다. 같은 질문 알림을 사용자가 접거나 연 뒤에는 반복하지 않는다. 질문 답변 초안과 전송 번호를 보관하며 응답 불명확 상태에서 자동 재전송하지 않는다.

공식 read_thread에는 request_user_input_async 카드가 생략되므로 project_questions.py가 등록된 로컬 대화의 기존 rollout을 읽기 전용으로 조회한다. 최초 최근 8MiB, 이후 추가된 부분만 읽고 파일 자체는 수정하지 않는다. 질문 본문·선택지·호출ID만 보관하며 전체 도구 출력/대화 기록을 Office로 복제하지 않는다. 새 입력·턴 교체·중지·실제 질문 답변 기록으로 과거 질문을 제외한다.

Office에서 제출한 답변은 실제 원래 대화의 현재 상태를 확인한 뒤 기존 project_panel_send 경로로 전달한다. 이는 비동기 확인 질문의 사용자 답변이며, 원래 Codex 질문 카드의 UI 제출/해결 상태까지 동기화됐다고 보장하지 않는다. 중지/실패 상태의 턴에는 전달하지 않는다.

명령 실행·파일/네트워크 접근권한 등 플랫폼 자체 승인은 실제 승인 화면에서 처리한다. 관찰한 승인 대기는 Office 작업창에도 표시하고 원래 승인 요청을 여는 동작을 제공한다. 일반 채팅 전송을 플랫폼 승인으로 가장하지 않는다. 원격 PC의 rollout 읽기나 원격 승인 응답을 지원한다고 주장하지 않는다.

검증: 저장 소스 구문 및 현재 실행 서버의 question_revision=2026-10-28-local-questions-v2 확인. 실제 9개 대화에서 질문 호출 15건/주관식 5건 파싱 관찰. 새 Office 화면의 질문 영역·알림 영역·스타일·기존 입력란 로딩 확인. 당시 미응답 질문 0건으로 실제 새 질문 팝업 및 사용자 답변 전송의 종단 확인은 아직 하지 않았다. 별도 테스트·유료 모델·시험용 메시지는 실행하지 않았다.
