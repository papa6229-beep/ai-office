# 레트로 계기판·콘솔과 상태별 프레임 · 2026-10-27

요청55d9a0ef050447918f141c5159ef167e는 앞선 레트로 제안을 적용하고 대기 중의 상시 팀색 테두리를 없애도록 승인했다. 후속70d030089b7a4b0c96058c3d28bc7aa6은 The Hand 답변에 남은 핑크를 블루로 바꾸고 사용자의 대화 카드 색은 원래대로 유지하도록 추가했다.

## 적용

상단 시계·날씨는 기존42px 높이 안에 스모크 유리·앰버 모노스페이스 숫자·작은 눈금을 넣고 날짜 버튼을 기계식 키처럼 표현했다. 채팅 제목의 선택 키와 입력 홈·전송 키에 장비 콘솔의 깊이를 더했다. 하단 업무/요청 제목은 아이보리 날짜·분류 명판으로 표현했다. 본문 글꼴·기존 레이아웃과 비대칭 모서리는 유지한다.

워크스페이스 카드는 실제 기존 data-state로 idle/unknown이면 회색, working/completed이면 팀색, attention이면 주의색을 표시한다. has-window/hover는 대기 카드의 팀색 테두리를 만들지 않는다. 팀 이름/그룹 제목의 핑크·블루는 정체성 표시로 유지한다.

총괄 상태창과 메인 작업창에는 기존 실제 native 상태·미확인 완료에서 유도한 data-frame-state를 표시한다. 기록 조회 중/갱신 지연은 회색이다. Aemeath의 실제 Office 별도 작업/완료·주의/알림 표시는 기존 실제 data-state/activity/attention을 존중한다. 기존 경고 알림 경로는 유지하며 일반 작업 테두리의 반복 애니메이션은 제거했다. 프로젝트 패널도 기존 departmentStatus/seen 판정으로 창 테두리를 동기화한다. 새 작업/완료를 만들거나 수신 확인 정책을 바꾼 기능이 아니다.

기존 사용자 메시지에 팀색을 넣던 override를 제거했다. 팀색은 .is-assistant의 왼쪽 테두리와 이름 라벨에만 적용한다. The Hand는 블루이고 사용자의 원래 올리브색 테두리·어두운 녹색 바탕·라임 라벨은 유지한다.
