# 브라우저 역할 분리

확정일: 2026-10-27

일반 인터넷 사용과 사용자에게 보여주는 외부 링크는 Windows 기본 브라우저인 Google Chrome으로 연다. 에이메스와 모든 부서·요원의 웹사이트 조작·로그인·입력·화면 확인은 설치된 ego-browser 스킬과 공식 Ego API를 사용한다. Windows 기본 브라우저 설정과 에이전트 작업 브라우저를 별도로 유지하며, Ego 작업을 위해 기본 브라우저를 Ego로 바꾸지 않는다. 기존 Chrome 전용 browser_*·Playwright 연결을 기본 실행 경로로 안내하거나 조용히 대체하지 않는다. 기존 성공 기록·계정·사용자 탭과 진행 중 작업은 보존하며 임의로 재실행하지 않는다. 등록 보고서는 기존 Ego 코드 실행기를 재사용한다. HTTP 자료 수집·공식 CLI·로컬 코드 처리는 기존 실행 경로를 유지한다.


## 사용자 화면·마우스 보존 (2026-10-27)

태준님의 현재 화면·마우스·키보드·포커스를 유지한다. 파일·정형 업무는 기존 코드 실행기, 외부 서비스는 공식 API·연결 도구·CLI, 웹 작업은 공식 Ego API를 우선한다. 사용자 화면을 활성화하거나 마우스·키보드를 가져오는 Computer Use를 자동 대체 경로로 쓰지 않는다. 백그라운드로 처리할 수 없는 Windows 설정·네이티브 앱 클릭은 필요한 창을 열어둘 수 있는 공식 경로를 사용하고, 태준님이 누를 버튼과 위치만 짧게 안내한다. Computer Use로 직접 화면을 조작하는 것은 태준님이 그 조작을 명시적으로 맡길 때만 수행한다. 그때도 미리 필요한 조작을 짧게 알리고 최소 조작 후 곧바로 입력을 멈춘다. 느린 화면 탐색이나 단계 사이의 긴 대기로 사용자 작업을 점유하지 않는다. 백그라운드 API·코드 사용은 기존 업무 권한과 플랫폼 승인·사용자 중지 경계를 유지하며, 실제 화면 입력이 필요한 동작을 백그라운드라고 주장하지 않는다. 사용자가 Esc로 중지하면 추가 화면 조작을 하지 않는다.
