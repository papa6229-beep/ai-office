# 메인 채팅의 전송 대상 구분

요청: c79d3bf51c1544f1bb454e3a2c668238. 첨부 화면과 supervisor-switch.js/css의 기존 두 총괄 선택·독립 입력창을 기준으로 한다.

판단: 기존 전송 경로를 유지하고 선택 표현을 강화한다. 단순 테두리 확대나 전송 때마다 확인창을 띄우는 방식보다, 선택 버튼과 작성 위치에 같은 이름·색을 반복하는 방식이 현재 오발송 문제에 맞다. 완료 조건은 어느 입력창이 보이든 선택된 상대를 이름·선택 문구·색으로 구별할 수 있는 것이다.

디자인: 기존 콘솔의 배경 #1b1c1f, 상승 면 #292a2d, 본문 #f2f0e8 및 현행 --office-aemeath/--office-hand 색을 재사용한다. Pretendard와 기존 모서리를 유지한다. 상단 선택 키는 선택한 팀색으로 채우고 '선택됨'을 표시한다. 해당 캐릭터 모니터에는 '대화 중' 명판을 붙인다. 입력창 바로 위에는 큰 상대 이름, 아래 전송 버튼에는 같은 이름을 표시한다. 입력 영역은 약한 팀색 면과 왼쪽 선으로 연결한다. 작업중·완료·주의 프레임 상태는 별개로 보존한다.

구조: 상단 [Aemeath 선택됨] [The Hand] → 선택된 모니터의 대화 중 표시 → [Aemeath | 운영본부] 입력창 → [Aemeath에게 / 기존 전송 동작]. 기존 레이아웃·캐릭터 GIF·초안·첨부·전송/추가전송/재확인 동작은 유지한다. 새 이미지나 애니메이션은 만들지 않는다.

검증: 요청에 따라 테스트는 추가·실행하지 않는다. JS 구문, diff, 기존 두 submit 차단과 대상 연결, 실제 제공된 UI 세대의 소스 해시를 확인한다. 별도 Ego 확인이 가능하면 사용자 앱과 구별해 기록한다. 사용 중인 앱을 재시작하거나 초안·메시지를 조작하지 않는다.
