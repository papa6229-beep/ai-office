# AI OFFICE 자연어 실행 비서

## 사용자 요구

채팅은 프로그램의 공통 조작 창이다. 사용자가 정해진 문장, 정확한 앱 철자,
영문 이름을 외우지 않아도 의도를 이해하고 설치 앱과 실제 업무 자료를 찾아 기능을 수행한다.
앱 등록에만 한정하지 않고 실행, 업무 기록, 자료 조사와 정리까지 같은 흐름으로 이어간다.

## 확인한 기반

- 현재 Gemma 4 26B 서버가 native tool calling을 지원하며 한국어 요청의 도구 호출을 확인했다.
- 기존 채팅은 정규식 분기와 업무 전용 JSON 분류여서 기능의 공통 실행 창이 아니었다.
- 앱 실행, 업무 DB, 바탕화면 조사, 가상 작업함, 복구 보관은 기존 서비스를 재사용한다.
- 가상 묶음과 실제 파일 이동은 별개의 결과로 표시한다.

## 설계

1. 모델에 대화와 도구 목록을 전달한다. 모델은 조회 결과를 받아 필요한 도구를 이어 호출한다.
2. 서버 등록부가 도구 이름, 인수와 현재 서버 참조를 검사하고 기존 서비스를 실행한다.
3. 앱 경로, AppID, 임의 코드 실행은 모델 인수로 받지 않는다.
4. 등록·업무 변경과 사용자 요청의 앱 열기를 지원한다. 실제 파일 이동·보관은 고정 대상과
   revision을 가진 승인 카드로 연결한다. 모델이 승인 여부를 만들어 낼 수 없다.
5. 완료 여부는 도구 실행 기록을 기준으로 보고한다. 앱 실행은 열기 요청으로 표시한다.
6. 요청·각 실행 단계·선택·승인을 비공개 DB에 보관한다. 같은 요청의 중복 실행과
   중단된 외부 동작의 자동 재실행을 막는다. 새로고침 후 선택·승인이 유지된다.
7. 미구현 메신저 대행·임의 화면 조작·영구 삭제는 지원 완료로 표시하지 않는다.

## 완료 조건

자연스러운 한국어로 앱 검색→등록/열기, 업무 기록, 바탕화면 조사→분석 결과→정리 승인
흐름이 동일한 채팅에서 실제 서비스와 연결되고, 재접속·재시도 시 결과가 유지되어야 한다.
실제 모델 및 Windows에서 검증하고 기존 사용자 파일·DB·설정을 보존한다.
