2026-10-28 사용자가 시안 06 적용을 승인했다. 부서명 배지는 우상단, 상태 배지는 하단 중앙이며 아이보리/회색/앰버/라임을 쓴다. 상태색 테두리가 점멸하고, 장면에는 불규칙한 옅은 가로 주사선, 배지와 테두리에는 은은한 발광이 들어간다. 기기 자체 외형과 중복되는 둥근 모서리·유리 반사는 합성하지 않는다.

대기·작업·완료는 각각 기존 idle/working/completed 판정을 재사용한다. 오피스가 닫혀 상태 수신이 끊기면 마지막 실제 표시를 유지한다. 장치 ACK는 전송 수락이며 물리 화면의 외형 확인과 구분한다. 실제 적용 기록은 기존 작업일지에 남긴다.
