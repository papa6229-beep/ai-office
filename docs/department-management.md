# 에이메스 부서관리

좌측 **에이메스 부서관리**에서 팀·요원·업무지침·스킬 참조·기술문서를 관리한다.

- 현재 운영본부, 기획부서, 디자인부서, 개발부서의 대표 요원은 기존 실제 Codex 대화를 사용한다. 대화 열기는 `project-panels.js`의 기존 창을 재사용하며 새 모델 작업을 시작하지 않는다.
- 부서 추가는 로컬 구성만 저장한다. 요원은 기존 AI OFFICE 대화를 연결하거나 사용자 버튼으로 새 대화를 만들 수 있다. 새 대화는 현재 앱 기본 모델을 사용하고 초기 응답에 사용량이 발생한다. 생성 결과가 불확실할 때는 자동 재생성하지 않고 Codex 목록을 확인한다.
- 자료는 부서 공통 또는 요원별이며 **초안 / 사용**으로 구분한다. 사용 자료만 해당 대화의 다음 오피스 전송에 적용된다. 역할·자료가 변경되면 한 번 전달하고 성공한 전송 뒤 확인 기록을 남긴다. 기존 본부 relay와 프로젝트 창 모두 같은 부서 자료 경로를 사용한다. 연결 해제 후에는 이전 부서 자료의 적용 중단을 전달한다.
- Codex 앱에서 직접 입력하는 요청에 부서 자료를 자동 주입하지는 않는다. 스킬 등록은 SKILL.md 경로·문서 링크·실행 절차를 전달하는 기능이며, 네이티브 스킬 설치 기능이 아니다.
- 자료의 편집과 조회는 Python/SQLite/JS가 처리한다. UI를 열거나 저장하기 위해 별도 모델을 호출하지 않는다. 실제 업무 메시지나 새 대화의 초기 응답에는 해당 모델 사용량이 발생한다.
- 노션 AI OFFICE 문서함 및 운영팀 구상 원본을 연결한다. 오피스 자료 저장은 로컬 저장이며 노션 본문 자동 동기화가 아니다. 노션 계정 토큰을 오피스 설정으로 복사하지 않는다. 연결 문서 원본은 노션에서 관리한다.
- 부서 자료는 office.db의 전용 registry/전송 확인/생성 접수 테이블에 저장한다. 일반·보고서 지침 카드를 수정하지 않는다. 요원 연결 해제나 오피스 자료 삭제가 Codex 대화나 노션 원본을 삭제하지 않는다.
- 대표·실장·부서의 실제 배정/완료보고는 `docs/department-dispatch.md`를 따른다. 팀별 상세 운영정책은 아직 확정하지 않았다.

2026-10-26: 구문 확인, 실제 화면의 네 부서 표시, 기획부서 기존 대화 읽기, 운영본부 노션 초안 링크 저장 및 새로 열기 후 유지 확인. 새 요원 대화 생성과 모델의 지침 수행은 실행하지 않았다. 별도 테스트는 추가·실행하지 않았다.

## 업무일지·달력

기본 탭의 전체 업무일지 또는 부서별 일지에서 월·날짜·팀으로 실제 배정 업무를 찾는다. 오늘·이달 전체 버튼과 이전/다음 달 이동을 제공하며 카드에서 기존 Notion 원문을 연다. 제목·팀·업무일시·상태와 짧은 진행 요약만 표시한다. 콘솔/실버 색상·글꼴을 상속하고 좁은 화면에서는 달력과 목록이 한 열이 된다.

카드의 **노션 반영 대기**는 로컬에 새 이력이 있지만 공식 연결의 성공 재조회/ack가 없다는 뜻이다. 원문 링크가 있다고 최신 이력이 동기화된 것은 아니다. 승인 거절 사유도 보존한다. 서버가 아직 이전 코드를 읽고 있으면 빈 목록 대신 서버 반영 대기를 안내하고 기존 배정업무 탭을 유지한다. 일지는 실제 배정·진행·결과와 중요한 일정·문서·결정만 대상으로 하며 일반 채팅 전문·사소한 질답은 저장하지 않는다.

Notion 달력 링크는 기존 업무일지 DB의 업무일시 view다. 로컬 달력은 확인된 속성의 snapshot과 미반영 배정 기록을 사용한다. 새 Calendar 계정이나 일정을 만들지 않는다. 실제 기록 방식과 pending/ack API는 `docs/department-journal.md`에 있다. 서버 반영·사용자 프로그램의 새 화면·공식 Notion 저장 검증은 각각 구분한다.


## 고도·메두사 전담 편성 (2026-10-27)

각 기존 부서에 godo 전담 요원을 추가했다. 기존 요원은 유지한다. 실제 네 전담창은 godo 프로젝트에 있고 조정·지원은 기존 고도 메두사 연결작업이다. 명단·Notion 기준·현재 연결/자동화 한계는 docs/godo-department-agents.md를 따른다. 현재 연결 검증은 동일 실제 등록 프로젝트의 요원/조정창을 확인하며, 과거 AI OFFICE cwd만 허용하던 경로와 구분한다. 새 대화를 실제 업무 없이 임의로 추가하거나 과거 문서의 업무를 자동 재개하지 않는다.
