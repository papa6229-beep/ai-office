공통 프로젝트/부서/The Hand 입력창은 전송 HTTP 응답에서 `sent`를 받은 경우만 입력을 정리하고 있었다. 응답을 놓친 뒤 이력 조회의 영수증에서 `sent`를 확인하는 경로는 말풍선 상태만 갱신해, 같은 메시지와 pending 전송번호가 입력창에 남을 수 있었다.

`project-panels.js`의 정리 함수를 공통화했다. 직접 응답과 나중의 영수증 조회 모두 같은 전송번호의 완료가 확인되면 현재 입력이 원래 전송문과 같을 때만 비운다. 바꿔 쓴 초안과 새 첨부는 보존하고 완료된 첨부만 제거한다. pending 저장값도 함께 정리한다. HTTP 응답을 기다리는 동안 확인된 영수증은 응답 처리 뒤 다시 대조한다. 이미 읽어 둔 말풍선 사본의 전달 상태도 맞춘다. 닫았다 다시 연 창에 이전 창의 비동기 응답이 영향을 주지 않도록 실제 창 인스턴스를 확인한다.

‘전달 확인 필요’ 말풍선 자체는 전달 완료 근거가 아니다. 완료가 확인되지 않은 전송은 입력과 첨부를 보존하며 자동 재전송하지 않는다. 같은 문구의 다른 전송번호를 완료 근거로 사용하지 않는다.

첨부 화면과 실제 코드·영수증 형식을 확인했고 Node 구문·diff를 확인했다. 테스트 추가/실행·메시지 전송·사용자 화면 조작은 하지 않았다. 첨부 문구와 일치하는 실제 영수증은 해당 HQ 기록에서 특정하지 못했으므로 그 메시지의 전달 완료를 단정하지 않는다. 브라우저의 실제 입력 정리·새 초안 보존 동작은 사용자 화면에서 미검증이다. 정상 화면 소스 게시 등록 후 사용자가 ‘새 버전 적용’을 직접 누른다.
