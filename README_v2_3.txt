AI OFFICE v2.3 · 프로젝트 ZIP 비교 통합판

1. 기존 AI OFFICE 실행창을 닫으세요.
2. 본 ZIP은 반드시 새로운 폴더에 압축 해제하세요. 기존 폴더에 덮어쓰지 마세요.
3. start.bat 실행, 브라우저 http://127.0.0.1:8765 접속.
4. 왼쪽 '프로젝트·버전 비교' 클릭 > 바탕화면 경로 입력 > 비교 시작.
5. 같은 폴더의 ZIP 파일만 대상으로 합니다 (최대 150개). ZIP 내부 파일 목록과 CRC 및 ZIP 자체 SHA256을 비교합니다.
6. 새 비교 기능은 읽기 전용이며 압축 풀기/파일 이동/삭제를 하지 않습니다.

주의: '기존 파일 정리' 메뉴에는 이전 버전의 승인 후 이동 기능이 그대로 남아 있습니다. 이번 ZIP 비교 기능과 별개입니다.
'최신본' 판정은 아직 구현하지 않았으며, 유사 압축 묶음은 후보입니다.
PDF, PSD, AI 등 파일의 시각/의미 내용 분석 및 Gemma 자동 분류도 아직 구현되지 않았습니다.
서버 접속 설정(settings.json)과 office.db는 원본 번들에서 유지했습니다. 기존 설치본에 최신 설정·업무 기록이 있으면 실행 종료 후 백업하여 신버전으로 옮겨야 합니다.
압축파일이 크거나 손상된 경우 건너뛰고 메시지를 표시할 수 있습니다.
